# 小明待办智能体

用中文记待办、看清单、标记完成或删除任务。输入“帮我记一下洗衣服”，再说“衣服洗好了”，小明会把原来的任务标记为已完成。聊天和任务 API 共用本地的 `data/tasks.json`。

## 运行

使用 Node.js 24.12 或更高版本，在仓库根目录执行：

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:3000>。下面的对话可以直接在无密钥环境下运行。若要启用 DeepSeek 解析更多中文表达，将 `.env.example` 复制为 `.env`，填写 `DEEPSEEK_API_KEY` 后重启。需要模型解析时，服务端会把最近的对话和当前任务清单发送给 DeepSeek。

## 六轮验收

在空清单里连续发送下列消息。可在另一个标签页打开 <http://127.0.0.1:3000/api/tasks>，每轮刷新该页核对数据。

| 用户对小明说     | 预期结果                                   |
| ---------------- | ------------------------------------------ |
| 帮我记一下买牛奶 | 新增待办「买牛奶」                         |
| 再记一条取快递   | 清单里多了一条「取快递」                   |
| 我有哪些任务？   | 列出两条任务，并能看出各自的完成状态       |
| 牛奶买好了       | 把「买牛奶」标记为已完成，「取快递」仍待办 |
| 取快递这条删掉吧 | 删除「取快递」                             |
| 再给我看看清单   | 只剩已完成的「买牛奶」                     |

完成第六轮后刷新聊天页，重新问“看看清单”。停止服务，在同一目录重新启动并再次询问。两次都应只剩同一 ID 的已完成任务“买牛奶”。

## 更多对话

| 想验证的行为   | 可以这样试                                                                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 区分相似任务   | 分别添加“取公司快递”和“取家里快递”，说“快递取了”。小明列出候选项后，回复“公司的”或“第一个”，只有选中的任务会变更。                                         |
| 取消或重复操作 | 在追问时回复“取消”。对已经完成的任务再说一次“牛奶买好了”，可以看到此前的完成状态。                                                                         |
| 查看部分清单   | “看看清单”按待办和已完成分组，“只看未完成任务”和“查看已完成任务”只返回对应分组。                                                                           |
| 查询到期日     | “记一下今天交报告”“记一条明天买菜”，再问“今天有哪些任务到期？”。日期按运行服务的本地时区解释，结果只含当天到期的未完成项。也可说“记一条 2028-02-29 还书”。 |

## 验证与实现

在根目录运行 `npm test`、`npm run typecheck`、`npm run lint`、`npm run fmt:check` 和 `npm run build`。自动化用例使用临时目录，模型分支使用测试替身，可以离线复现。

服务端先识别常见指令。其他说法在配置密钥后由 DeepSeek 输出结构化意图，Zod 校验动作与参数，执行层核实目标 ID 并依据存储结果回复。多条记录匹配时会询问用户。实现入口见[智能体](server/agent.ts)、[意图解析](server/intent.ts)和[模型客户端](server/model.ts)。

支持单用户、本地单服务进程和单项操作。聊天记录随页面刷新清空，服务重启后需要重新发起尚未回答的选择。到期日用于查询，应用不发送定时通知。运行细节见[开发指南](GETTING_STARTED.md)，接口字段见 [OpenAPI](server/openapi.yaml)，题目与评价标准见[官方模板](https://github.com/TokeNow/todo-agent)。

## 模型费用
